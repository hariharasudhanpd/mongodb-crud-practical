
# MongoDB CRUD Operations and Query Operators

## Project Description
This project demonstrates the basic operations of MongoDB using a Student Database.

## Objective
To understand MongoDB database creation, collections, CRUD operations, and query operators.

## Technologies Used
- MongoDB
- MongoDB Shell (mongosh)
- Visual Studio Code

## Operations Performed
1. Database and Collection Creation
2. Insert One and Multiple Documents
3. Read and Filter Documents
4. Update One and Multiple Documents
5. Delete One and Multiple Documents
6. MongoDB Query Operators:
   - $gt
   - $lt
   - $in
   - $and
   - $or
   - $exists

## Real-World Use Case
Library Management System using MongoDB.

Refer to MongoDB-CRUD-Practical.pdf for screenshots of practical execution.

Successfully practiced MongoDB CRUD operations and query operators using MongoDB Shell.
